# 1과. Sequence Slicing & Mutable Sequence & 얕은 복사

## 1. Sequence 타입의 Slicing 연산

Slicing은 Sequence의 일부분을 잘라서 가져오는 연산이다.

기본 형태:

```python
s[m:n]
s[m:n:k]
```

* `s` : Sequence 타입의 Iterable
* `m` : 시작 위치
* `n` : 종료 위치
* `k` : 간격(step)

> ⭐ Slicing의 핵심은 **시작 `m`은 포함하고, 종료 `n`은 포함하지 않는다.**

---

### `s[m:n]`

`m`번 item부터 시작해서 **1씩 증가**하며 `n`번 직전까지 가져온다.

```python
s = [0, 1, 2, 3, 4, 5]

print(s[1:4])
```

출력:

```text
[1, 2, 3]
```

즉,

```text
s[1:4]

1 → 포함
2 → 포함
3 → 포함
4 → ❌ 종료
```

---

### `s[m:n:k]`

`k`는 **몇 칸씩 이동할지**를 의미한다.

#### `k`가 양수

`m`부터 시작해서 `k`씩 증가한다.

```python
s = [0, 1, 2, 3, 4, 5, 6]

print(s[1:6:2])
```

출력:

```text
[1, 3, 5]
```

```text
1 → 3 → 5 → 6 이상이므로 종료
```

---

#### `k`가 음수

`m`부터 시작해서 `k`씩 **감소**한다.

```python
s = [0, 1, 2, 3, 4, 5, 6]

print(s[5:1:-1])
```

출력:

```text
[5, 4, 3, 2]
```

```text
5 → 4 → 3 → 2 → 1에서 종료
```

> ⭐ 음수 step을 사용할 때는 **시작 위치가 종료 위치보다 뒤에 있어야 한다.**

---

### Slicing 핵심

```text
s[m:n]
→ m부터 시작해서 1씩 증가
→ n은 포함하지 않음

s[m:n:k]
→ m부터 시작해서 k씩 이동
→ k > 0 : 증가
→ k < 0 : 감소
→ n은 포함하지 않음
```

# 2. Mutable Sequence 타입의 연산 및 메서드

Mutable Sequence는 **수정 가능한 Sequence**를 의미한다.

대표적으로:

```text
list
```

가 있다.

---

## `s += t`

`s` 뒤에 `t`를 연결한다.

```python
s = [1, 2]
t = [3, 4]

s += t

print(s)
```

출력:

```text
[1, 2, 3, 4]
```

---

## `s.extend(t)`

`t`의 item들을 **하나씩 풀어서** `s` 뒤에 연결한다.

```python
s = [1, 2]

s.extend([3, 4, 5])

print(s)
```

출력:

```text
[1, 2, 3, 4, 5]
```

### `append()`와 비교

```python
s = [1, 2]

s.append([3, 4])
```

결과:

```text
[1, 2, [3, 4]]
```

반면:

```python
s = [1, 2]

s.extend([3, 4])
```

결과:

```text
[1, 2, 3, 4]
```

> ⭐
>
> ```text
> append(t) → t 자체를 하나의 item으로 추가
> extend(t) → t를 풀어서 item들을 추가
> ```

---

## `s *= n`

`s`의 내용을 `n`번 반복한다.

```python
s = [1, 2]

s *= 3

print(s)
```

출력:

```text
[1, 2, 1, 2, 1, 2]
```

---

## `del s[m]`

특정 위치의 item을 삭제한다.

```python
s = [10, 20, 30, 40]

del s[1]

print(s)
```

출력:

```text
[10, 30, 40]
```

---

## `s.reverse()`

리스트의 **원본 순서를 뒤집는다.**

```python
s = [1, 2, 3, 4]

s.reverse()

print(s)
```

출력:

```text
[4, 3, 2, 1]
```

> ⚠️ `reverse()`는 새로운 리스트를 만드는 것이 아니라 **원본 리스트 자체를 변경**한다.

---

# 3. Iterable의 Item 존재 여부 판단

`in`, `not in`을 사용하면 Iterable 안에 특정 값이 존재하는지 확인할 수 있다.

## `x in it`

`it` 안에 `x`와 같은 item이 하나라도 있으면 `True`

```python
x = 3
it = [1, 2, 3, 4]

print(x in it)
```

출력:

```text
True
```

---

## `x not in it`

`it` 안에 `x`와 같은 item이 없으면 `True`

```python
x = 5
it = [1, 2, 3, 4]

print(x not in it)
```

출력:

```text
True
```

### 정리

```text
x in it
→ x가 있으면 True
→ x가 없으면 False

x not in it
→ x가 있으면 False
→ x가 없으면 True
```

---

# 4. 얕은 복사 (Shallow Copy)

얕은 복사는 **바깥쪽 컨테이너만 새로 만들고, 내부 객체는 기존 객체와 공유하는 복사**이다.

대표적인 방법:

```python
b = a[:]
```

또는

```python
b = a.copy()
```

---

## 기본적인 예

```python
a = [1, 2, 3]

b = a[:]

a[0] = 100

print(a)
print(b)
```

결과:

```text
[100, 2, 3]
[1, 2, 3]
```

`a`와 `b`는 서로 다른 리스트이기 때문에 `a[0]`을 수정해도 `b`에는 영향을 주지 않는다.

---

# 5. 얕은 복사에서 중요한 것

문제는 **리스트 안에 또 다른 mutable 객체가 있을 때** 발생한다.

```python
a = [0, 1, 2, 3, [0, 1, 2]]

b = a[:]
```

이때 구조를 그림으로 생각하면:

```text
a ──→ [0, 1, 2, 3, ───────→ [0, 1, 2]]
                       ↘
b ──→ [0, 1, 2, 3, ───────→ 같은 리스트
```

바깥 리스트는 새로 만들어졌지만,

```text
[0, 1, 2]
```

라는 **내부 리스트는 a와 b가 공유**한다.

---

## 실제 수정

```python
a = [0, 1, 2, 3, [0, 1, 2]]

b = a[:]

a.insert(1, 100)

a[0] = 88

a[5].insert(2, 99)

print(a)
print(b)
```

결과:

```text
a → [88, 100, 1, 2, 3, [0, 1, 99, 2]]

b → [0, 1, 2, 3, [0, 1, 99, 2]]
```

### 왜 이렇게 될까?

#### `a.insert(1, 100)`

바깥 리스트 `a` 자체를 수정한다.

```text
a → 변경됨
b → 변경되지 않음
```

#### `a[0] = 88`

역시 바깥 리스트 `a`의 item을 교체한다.

```text
a → 변경됨
b → 변경되지 않음
```

#### `a[5].insert(2, 99)`

`a[5]`에 있는 **내부 리스트 자체를 수정**한다.

이 내부 리스트는 `a`와 `b`가 공유하고 있기 때문에:

```text
a → 변경됨
b → 같이 변경됨
```

---

# 6. 얕은 복사의 핵심

```text
얕은 복사

바깥 컨테이너
→ 새로 생성

내부 객체
→ 기존 객체를 그대로 참조
```

따라서:

```text
바깥 리스트의 item을 교체
→ 서로 영향 없음

공유하고 있는 내부 객체를 수정
→ 서로 영향 있음
```

---

# 7. 조금 더 복잡한 예제

```python
c = (1, 2)

d = [3, 4]

a = [c, d, 3, (5, 6)]

b = a[:]
```

구조를 보면:

```text
a ──→ [ c, d, 3, (5,6) ]
       ↓  ↓
      tuple list

b ──→ [ c, d, 3, (5,6) ]
       ↑  ↑
      공유 공유
```

`a`와 `b`의 **바깥 리스트는 서로 다르지만**, 안에 들어 있는 `c`, `d` 등의 객체는 같은 객체를 가리킨다.

---

## `c = list(c)`

```python
c = list(c)
```

이것은 `c`가 가리키는 대상을 **새로운 리스트로 바꾸는 것**이다.

```text
기존:
c ──→ (1, 2)

변경:
c ──→ [1, 2]
```

하지만 `a`와 `b`가 가지고 있는 것은 기존 `(1, 2)` 객체에 대한 참조이므로 영향을 받지 않는다.

> ⭐ 중요한 포인트
>
> **변수를 다른 객체에 연결하는 것**과
> **객체 자체를 수정하는 것**은 다르다.

---

## `a[2] = 4`

```python
a[2] = 4
```

`a`의 세 번째 item을 `3`에서 `4`로 **교체**한다.

```text
a → [c, d, 4, (5, 6)]
b → [c, d, 3, (5, 6)]
```

바깥 리스트가 서로 다르기 때문에 `b`에는 영향을 주지 않는다.

---

## `a[3] = (7, 8, 9)`

```python
a[3] = (7, 8, 9)
```

마찬가지로 `a`의 네 번째 item을 **새로운 tuple로 교체**한다.

```text
a → [c, d, 4, (7, 8, 9)]
b → [c, d, 3, (5, 6)]
```

`b`에는 영향을 주지 않는다.

---

## `d.append(99)`

여기가 가장 중요하다.

```python
d.append(99)
```

`d`는 리스트이고, `a`와 `b`가 **같은 리스트 객체를 공유**하고 있다.

따라서 `d` 자체를 수정하면 `a`, `b` 모두에서 변경된 내용이 보인다.

```text
a → [c, [3, 4, 99], 4, (7, 8, 9)]

b → [c, [3, 4, 99], 3, (5, 6)]

d → [3, 4, 99]
```

# 8. ⭐ "변수 변경"과 "객체 수정" 구분하기

얕은 복사를 이해할 때 가장 중요한 부분이다.

### ① 새로운 객체를 변수에 연결

```python
c = list(c)
```

```text
c → 새로운 리스트
```

기존 객체와 연결이 끊어진다.

---

### ② 객체 자체를 수정

```python
d.append(99)
```

```text
d가 가리키는 리스트 자체가 변경됨
```

`a`, `b`가 같은 리스트를 가리키고 있다면 **둘 다 변경된 결과를 보게 된다.**

---

# ⭐ 얕은 복사 핵심 그림

```text
                    얕은 복사

        a ─────────→ [ A, B, C ]
                       ↓  ↓  ↓
                       │  │  └── 객체
                       │  └───── 객체
                       └──────── 객체
       
        b ─────────→ [ A, B, C ]
                       ↓  ↓  ↓
                       │  │  └── 같은 객체
                       │  └───── 같은 객체
                       └──────── 같은 객체
```

```text
a[:] / a.copy()

        바깥 컨테이너 → 새로 생성
        내부 객체     → 기존 객체 공유
```
