

얕은 복사(a[:],a.copy)
바깥 컨테이너만 새로 만든다. 그안에 있는 객체에 대한 참조는 그대로 복사
1레벨에 있는건 상관없는데 한번더 쌓여져 있는 친구들은 주소값을 가지고 있으니
그친구가 변화가 생기면 변화가 여기에도 적용된다.
(ex)
a = [0,1,2,3,[0,1,2]]
b = a[:]

a.insert(1,100)
a[0]=88
a[5].insert(2,99)
print(a) => [88, 100, 1, 2, 3, [0, 1, 99, 2]]
print(b) => [0, 1, 2, 3, [0, 1, 99, 2]]




c = (1, 2)
d = [3, 4]

a = [c, d,3,(5,6)]
b = a[:]

print('처음')
print('a:', a) 
# [(1, 2), [3, 4]]
print('b:', b)

# c라는 변수에 새로운 리스트를 연결
c = list(c)
a[2]= 4
# d는 a와 공유하고 있는 리스트이므로 수정하면 a에도 반영
a[3] =(7,8,9)
# 2레벨 단이라 적용이 안되나봄
d.append(99)

print('\n수정 후')
print('a:', a) 
# c가 리스트로 바뀌었지만 여기에 영향 x => 껍데기가 다르니까, 새로운 껍데기를 만들면 다른 객체임
print('b:', b)
# 1레벨 단에있는 3->4 는 적용 x , 2레벨부터 영향
print('c:', c)
print('d:', d)
