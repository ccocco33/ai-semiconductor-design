# 10과. 주요 Container 메서드

# 1. Mutable Sequence Type 연산 정리

대표적인 Mutable Sequence는 `list`이다.

```python
s = [10, 20, 30, 40]
```

Mutable Sequence는 생성된 후에도 **요소를 추가, 삭제, 변경**할 수 있다.

---

## 1-1. `pop()`

```python
s.pop(index)
```

지정한 인덱스의 요소를 **삭제하면서 그 값을 반환**한다.

`index`를 생략하면 마지막 요소(`-1`)를 삭제한다.

```python
s = [10, 20, 30, 40]

x = s.pop(1)

print(x)
print(s)
```

결과:

```text
20
[10, 30, 40]
```

### 인덱스 생략

```python
s = [10, 20, 30]

x = s.pop()

print(x)
print(s)
```

결과:

```text
30
[10, 20]
```

### 주의

존재하지 않는 인덱스를 사용하면 `IndexError`가 발생한다.

```python
s.pop(10)
```

→ `IndexError`

### ⭐ 핵심

```text
pop()
→ 삭제 + 반환

pop(index)
→ index 위치 삭제 + 그 값 반환

pop()
→ 마지막 요소 삭제 + 반환
```

---

# 1-2. `remove()`

```python
s.remove(x)
```

리스트에서 `x`와 **같은 첫 번째 요소를 삭제**한다.

```python
s = [10, 20, 30, 20]

s.remove(20)

print(s)
```

결과:

```text
[10, 30, 20]
```

`20`이 두 개 있지만 **첫 번째 20만 삭제**된다.

### 반환값

`remove()`는 삭제만 하고 값을 반환하지 않는다.

```python
x = s.remove(30)

print(x)
```

→ `None`

### 없는 값을 삭제하면

```python
s.remove(100)
```

→ `ValueError`

### ⭐ pop과 비교

```text
pop()
→ 위치(index)로 삭제
→ 삭제한 값을 반환

remove()
→ 값(value)으로 삭제
→ 반환값 없음
```

---

# 1-3. `sort()`

```python
s.sort(*, key=None, reverse=False)
```

리스트 자체의 요소를 정렬한다.

```python
s = [30, 10, 20]

s.sort()

print(s)
```

결과:

```text
[10, 20, 30]
```

기본값은 **오름차순**이다.

### 내림차순

```python
s.sort(reverse=True)
```

결과:

```text
[30, 20, 10]
```

### `key` 사용

```python
s.sort(key=lambda x: x[1])
```

→ `x[1]`을 기준으로 정렬

### ⭐ 중요한 점

`sort()`는 **원본 리스트 자체를 변경**한다.

```python
s.sort()
```

그리고 반환값은 `None`이다.

```python
x = s.sort()

print(x)
```

결과:

```text
None
```

### `sort()`와 `sorted()` 비교

```text
s.sort()
→ 원본 리스트를 정렬
→ 반환값 None

sorted(s)
→ 새로운 리스트를 만들어 정렬
→ 원본은 그대로
→ 정렬된 list 반환
```

# 2. Set 연산자와 메서드

Set은 **집합**을 표현하는 Container이다.

```python
s = {1, 2, 3}
t = {3, 4, 5}
```

Set에서는 집합의 **합집합, 교집합, 차집합** 등의 연산을 할 수 있다.

---

# 3. Set의 포함 여부

## `in`

```python
x in s
```

`x`가 set에 존재하면 `True`

```python
s = {1, 2, 3}

print(2 in s)
```

결과:

```text
True
```

---

## `not in`

```python
x not in s
```

`x`가 set에 존재하지 않으면 `True`

```python
print(5 not in s)
```

결과:

```text
True
```

---

# 4. 합집합

## `union()`

```python
s.union(t)
```

두 집합의 **모든 요소를 합친 집합**을 반환한다.

```python
s = {1, 2, 3}
t = {3, 4, 5}

print(s.union(t))
```

결과:

```text
{1, 2, 3, 4, 5}
```

`3`은 중복되므로 한 번만 존재한다.

### 연산자로도 가능

```python
s | t
```

→ 합집합

```text
union()
=
|
```

---

# 5. 교집합

## `intersection()`

```python
s.intersection(t)
```

두 집합에 **공통으로 존재하는 요소**를 반환한다.

```python
s = {1, 2, 3}
t = {3, 4, 5}

print(s.intersection(t))
```

결과:

```text
{3}
```

### 연산자

```python
s & t
```

→ 교집합

```text
intersection()
=
&
```

---

# 6. 차집합

## `difference()`

```python
s.difference(t)
```

`s`에는 있지만 `t`에는 없는 요소를 반환한다.

```python
s = {1, 2, 3}
t = {3, 4, 5}

print(s.difference(t))
```

결과:

```text
{1, 2}
```

### 연산자

```python
s - t
```

→ 차집합

```text
difference()
=
-
```

### 방향이 중요하다

```python
s - t
```

와

```python
t - s
```

는 다르다.

```text
s - t → s에만 있는 것
t - s → t에만 있는 것
```

---

# 7. 대칭 차집합

## `symmetric_difference()`

두 집합 중 **한쪽에만 존재하는 요소**를 반환한다.

```python
s = {1, 2, 3}
t = {3, 4, 5}

print(s.symmetric_difference(t))
```

결과:

```text
{1, 2, 4, 5}
```

공통 요소인 `3`은 제외된다.

### 생각하는 방법

```text
s - t → {1, 2}
t - s → {4, 5}

둘을 합치면
→ {1, 2, 4, 5}
```

즉,

```text
대칭 차집합
=
(s - t) ∪ (t - s)
```

### 연산자

```python
s ^ t
```

→ 대칭 차집합

```text
symmetric_difference()
=
^
```

---

# 8. 집합 관계 확인

## `isdisjoint()`

```python
s.isdisjoint(t)
```

두 집합에 **공통 요소가 없으면 `True`**를 반환한다.

```python
s = {1, 2}
t = {3, 4}

print(s.isdisjoint(t))
```

결과:

```text
True
```

공통 요소가 있으면:

```python
s = {1, 2}
t = {2, 3}

print(s.isdisjoint(t))
```

결과:

```text
False
```

### ⭐ 암기

```text
disjoint = 서로 겹치지 않음

isdisjoint()
→ 서로 겹치지 않으면 True
```

---

# 9. `issubset()`

```python
s.issubset(t)
```

`s`의 모든 요소가 `t` 안에 있으면 `True`.

즉,

```text
s ⊆ t
```

인지 확인한다.

```python
s = {1, 2}
t = {1, 2, 3}

print(s.issubset(t))
```

결과:

```text
True
```

### 연산자

```python
s <= t
```

→ `s`가 `t`의 부분집합인지 확인

---

# 10. `issuperset()`

```python
s.issuperset(t)
```

`t`의 모든 요소가 `s` 안에 있으면 `True`.

즉,

```text
s ⊇ t
```

인지 확인한다.

```python
s = {1, 2, 3}
t = {1, 2}

print(s.issuperset(t))
```

결과:

```text
True
```

### 연산자

```python
s >= t
```

→ `s`가 `t`의 상위집합인지 확인

# 11. Set 요소 추가 / 삭제

## `add()`

```python
s.add(x)
```

set에 요소 하나를 추가한다.

```python
s = {1, 2, 3}

s.add(4)

print(s)
```

결과:

```text
{1, 2, 3, 4}
```

이미 존재하는 값을 추가해도 중복되지 않는다.

```python
s.add(3)
```

→ 변화 없음

# 12. `remove()`

```python
s.remove(x)
```

set에서 `x`를 삭제한다.

```python
s = {1, 2, 3}

s.remove(2)

print(s)
```

결과:

```text
{1, 3}
```

없는 요소를 삭제하면:

```python
s.remove(10)
```

→ `KeyError`

> ⚠️ List의 `remove()`는 없는 값을 삭제하면 `ValueError`지만,
> **Set의 `remove()`는 `KeyError`가 발생한다.**

---

# 13. `discard()`

```python
s.discard(x)
```

set에서 `x`를 삭제한다.

`remove()`와 거의 같지만 중요한 차이가 있다.

```python
s = {1, 2, 3}

s.discard(2)
```

→ `2` 삭제

없는 값을 삭제해도:

```python
s.discard(10)
```

→ **에러가 발생하지 않는다.**

### ⭐ remove vs discard

```text
remove(x)
→ 없으면 KeyError

discard(x)
→ 없어도 아무 일 없음
```

---

# 14. Set `pop()`

```python
s.pop()
```

set에서 **임의의 요소 하나를 삭제하고 반환**한다.

```python
s = {10, 20, 30}

x = s.pop()

print(x)
print(s)
```

여기서 어떤 값이 나올지는 **set의 순서를 기준으로 예측하면 안 된다.**

> ⭐ List의 `pop()`과 다르다.

```text
List pop()
→ 특정 index의 요소 삭제

Set pop()
→ 임의의 요소 하나 삭제
```

# 18. ⭐ 부분집합 / 상위집합

```python
s = {1, 2}
t = {1, 2, 3}
```

```python
s.issubset(t)
```

→ `s`가 `t`의 **부분집합**

```text
True
```

반대로:

```python
t.issuperset(s)
```

→ `t`가 `s`의 **상위집합**

```text
True
```

연산자로도 표현할 수 있다.

```text
s <= t  → s가 t의 부분집합
t >= s  → t가 s의 상위집합
```

# 19. ⭐ Set 메서드 전체 암기

### 집합 연산

```text
union()                  → 합집합
intersection()           → 교집합
difference()             → 차집합
symmetric_difference()   → 대칭 차집합
```

### 관계 확인

```text
isdisjoint()  → 서로 겹치지 않는가?
```

```text

```

# 🔥 시험용 최종 정리

## List

```text
pop(index)
→ index로 삭제 + 삭제한 값 반환
→ 없으면 IndexError

remove(x)
→ 값으로 첫 번째 요소 삭제
→ 반환값 없음
→ 없으면 ValueError

sort()
→ 원본 list 정렬
→ 반환값 None
```

## Set

```text
add(x)
→ 추가

remove(x)
→ 삭제
→ 없으면 KeyError

discard(x)
→ 삭제
→ 없어도 에러 X

pop()
→ 임의의 요소 삭제 + 반환

clear()
→ 전체 삭제

copy()
→ 복사
```

## Set 연산

```text
s | t  → 합집합
s & t  → 교집합
s - t  → 차집합
s ^ t  → 대칭 차집합
```

```text
union()
intersection()
difference()
symmetric_difference()
```

## 집합 관계

```text
s.isdisjoint(t)
→ 공통 요소 없음 → True

s.issubset(t)
→ s ⊆ t → True

s.issuperset(t)
→ s ⊇ t → True
```
