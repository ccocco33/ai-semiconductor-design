# 1. 프로젝트 개요

## 1.1 프로젝트명

* 프로젝트명 : 다인용 CNN 기반 가위바위보 판별 시스템

## 1.2 프로젝트 배경

* 카메라를 통해 여러 사람의 손동작을 실시간으로 인식하고, CNN 기반 이미지 분류 모델을 이용하여 가위, 바위, 보를 판별한다.
* 판별된 결과를 바탕으로 2명 이상의 참가자가 가위바위보를 진행할 수 있는 시스템을 구현한다.

## 1.3 프로젝트 목적

* CNN 기반 이미지 분류 모델을 활용하여 사람의 손동작을 가위, 바위, 보로 분류한다.
* 카메라를 이용하여 2명 이상의 참가자의 손동작을 동시에 인식한다.
* 인식된 손동작을 비교하여 가위바위보의 결과를 판단하고 화면에 표시한다.
* 학습된 CNN 모델을 Raspberry Pi에서 실행하여 On-device AI 시스템을 구현한다.

## 1.4 프로젝트 요약

> 카메라로 2명 이상의 참가자의 손동작을 입력받아 CNN 모델이 가위, 바위, 보를 각각 인식하고, 참가자별 선택 결과와 최종 승패 결과를 Raspberry Pi 화면에 실시간으로 표시하는 시스템을 구현한다.

# 3. 프로젝트 기능

## 3.1 주요 기능

| 기능         | 설명                                             |
| ---------- | ---------------------------------------------- |
| 카메라 입력     | 카메라를 통해 2명 이상의 참가자의 손동작을 실시간으로 입력받는다.          |
| 사람/손 영역 인식 | 화면에서 각 참가자의 손 영역을 찾아 CNN 모델의 입력으로 사용한다.        |
| 이미지 전처리    | 검출된 손 이미지를 CNN 모델의 입력 크기에 맞게 Resize 및 정규화한다.   |
| AI 추론      | CNN 모델을 이용하여 각 참가자의 손동작을 가위, 바위, 보 중 하나로 분류한다. |
| 참가자별 결과 표시 | 각 참가자의 가위바위보 선택 결과를 화면에 표시한다.                  |
| 승패 판단      | 참가자들의 선택 결과를 비교하여 승자, 패자 또는 무승부를 판단한다.         |
| 최종 결과 출력   | 가위바위보가 종료되면 최종 결과를 화면에 표시한다.                   |

## 3.2 사용자 동작

1. 2명 이상의 참가자가 카메라 앞에 위치한다.
2. 각 참가자가 손을 이용하여 가위, 바위 또는 보를 선택한다.
3. 카메라가 참가자들의 손동작을 촬영하고 CNN 모델이 각 손동작을 분류한다.
4. 시스템이 참가자별 선택 결과를 화면에 표시하고, 선택 결과를 비교하여 승패 또는 무승부를 표시한다.

# 4. 시스템 구성

## 4.1 전체 시스템

```text
[펭카 PCWEB400 웹캠]
          ↓
     [영상 입력]
          ↓
    [OpenCV 처리]
          ↓
 [YOLO 객체 검출 모델]
          ↓
 [참가자 수 및 손 영역 검출]
          ↓
 [P1(왼쪽) / P2(오른쪽) 구분]
          ↓
   [참가자 2명 입장 확인]
          ↓
    [3초 카운트다운]
          ↓
 [손 영역 전처리 및 크기 조정]
          ↓
     [CNN Model]
          ↓
 [P1 / P2 가위바위보 판별]
          ↓
    [승패 결과 판단]
          ↓
      [결과 출력]
```

## 4.2 시스템 구성 요소

| 구성 요소             | 역할                                                                   |
| ----------------- | -------------------------------------------------------------------- |
| Camera            | 펭카 PCWEB400 웹캠을 사용하여 참가자의 영상과 손동작을 실시간으로 촬영한다.                       |
| Raspberry Pi      | Raspberry Pi 5 Model B에서 영상 처리, YOLO 및 CNN 모델 추론, 게임 진행을 제어한다.       |
| YOLO Model        | 카메라 영상에서 참가자 또는 손 영역을 검출하고, 검출된 객체의 위치와 경계 상자(Bounding Box)를 제공한다.   |
| CNN Model         | YOLO를 통해 검출된 손 영역을 입력받아 가위, 바위, 보 중 하나로 분류한다.                        |
| TFLite/LiteRT     | 학습된 CNN 또는 YOLO 모델을 Raspberry Pi에서 실행하기 위한 경량화 모델 형식 및 추론 환경으로 사용한다. |
| OpenCV            | 웹캠 영상 입력, 프레임 처리, 이미지 전처리 및 결과 화면 출력을 담당한다.                          |
| YOLO Detection    | 영상에 나타난 참가자 수와 손 영역을 검출하고 각 객체의 위치 정보를 제공한다.                         |
| Player Position   | 화면 기준 왼쪽 참가자를 P1, 오른쪽 참가자를 P2로 구분한다.                                 |
| Countdown         | 참가자 2명이 입장하면 3초 카운트다운을 진행한 후 게임을 시작한다.                               |
| Result Processing | P1과 P2의 가위바위보 결과를 비교하여 승리, 무승부 또는 패배를 판단한다.                          |
| Display           | 참가자 수 안내, 카운트다운, 플레이어별 선택 결과 및 승/무/패 텍스트를 출력한다.                      |

| Game Logic      | 참가자 수 확인, P1/P2 구분 및 승패 판단 |

## 4.5 YOLO와 CNN의 역할 분담

본 프로젝트에서는 YOLO와 CNN을 각각 다른 목적으로 사용한다.

| 모델   | 담당 기능               | 출력 결과                       |
| ---- | ------------------- | --------------------------- |
| YOLO | 영상에서 참가자 또는 손 영역 검출 | 객체 위치, Bounding Box, 검출 신뢰도 |
| CNN  | 검출된 손 이미지의 가위바위보 분류 | 가위, 바위, 보 중 하나              |

### 처리 순서

1. YOLO가 카메라 영상에서 참가자의 손 영역을 검출한다.
2. 검출된 Bounding Box를 이용하여 손 이미지를 추출한다.
3. 추출한 손 이미지를 CNN 입력 크기에 맞게 Resize 및 정규화한다.
4. CNN 모델이 손동작을 가위, 바위, 보로 분류한다.
5. 각 참가자의 예측 결과를 비교하여 게임 결과를 판단한다.

> YOLO는 **어디에 손이 있는지 검출**하고, CNN은 **검출된 손이 어떤 동작인지 분류**한다.

## 4.6 참가자 수에 따른 동작

| 참가자 수 | 시스템 동작 및 출력 텍스트                         |
| ----- | --------------------------------------- |
| 0명    | `플레이어를 기다리는 중입니다.`                      |
| 1명    | `플레이어 1명이 감지되었습니다. 다른 플레이어를 기다리는 중입니다.` |
| 2명    | `P1과 P2가 입장했습니다.` → `3초 카운트다운` → 게임 시작  |
| 3명 이상 | `플레이어가 너무 많습니다. 2명만 입장해주세요.`            |

참가자 수는 YOLO의 검출 결과를 기반으로 확인한다. 실제 참가자 수를 정확하게 판단하기 위해서는 YOLO가 학습한 객체 클래스와 검출 기준을 프로젝트에 맞게 설정해야 한다.

## 4.7 플레이어 구분

* **P1(Player 1)**: 카메라 화면 기준 왼쪽에 위치한 참가자
* **P2(Player 2)**: 카메라 화면 기준 오른쪽에 위치한 참가자

YOLO가 검출한 객체의 Bounding Box 중심 좌표를 기준으로 참가자의 좌우 위치를 판단한다.

| 플레이어 | 위치     | 출력 예시    |
| ---- | ------ | -------- |
| P1   | 화면 왼쪽  | `P1: 가위` |
| P2   | 화면 오른쪽 | `P2: 바위` |

## 4.8 게임 진행 흐름

1. 펭카 PCWEB400 웹캠을 통해 영상을 입력받는다.
2. OpenCV를 이용하여 카메라 영상을 프레임 단위로 처리한다.
3. YOLO 모델을 이용하여 영상 속 참가자 또는 손 영역을 검출한다.
4. 검출된 결과를 이용하여 참가자 수를 확인한다.
5. 참가자가 1명일 경우 추가 참가자를 기다린다는 안내 문구를 출력한다.
6. 참가자가 3명 이상일 경우 2명만 입장하도록 안내 문구를 출력한다.
7. 참가자가 정확히 2명일 경우 화면 기준 왼쪽을 P1, 오른쪽을 P2로 구분한다.
8. P1과 P2가 입장하면 3초 카운트다운을 진행한다.
9. 카운트다운이 종료되면 가위바위보 게임을 시작한다.
10. YOLO가 검출한 손 영역을 추출하고 CNN 입력 크기에 맞게 전처리한다.
11. CNN 모델을 이용하여 P1과 P2의 손동작을 추론한다.
12. 각 플레이어의 손동작을 가위, 바위, 보 중 하나로 판별한다.
13. P1과 P2의 선택 결과를 비교하여 승리, 무승부 또는 패배를 판단한다.
14. 플레이어별 선택 결과와 승/무/패 결과를 화면에 출력한다.

## 4.9 결과 출력

| 상황        | 출력 예시                        |
| --------- | ---------------------------- |
| P1 승리     | `P1: 가위 / P2: 보`<br>`P1 승리`  |
| P2 승리     | `P1: 바위 / P2: 보`<br>`P2 승리`  |
| 무승부       | `P1: 가위 / P2: 가위`<br>`무승부`   |
| 게임 준비     | `P1과 P2가 입장했습니다.`            |
| 카운트다운     | `게임 시작까지 3초`                 |
| 참가자 1명    | `플레이어 1명이 감지되었습니다.`          |
| 참가자 3명 이상 | `플레이어가 너무 많습니다. 2명만 입장해주세요.` |
