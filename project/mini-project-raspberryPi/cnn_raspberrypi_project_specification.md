# 1. 프로젝트 개요

## 1.1 프로젝트명

* 프로젝트명 : 다인용 CNN 기반 가위바위보 판별 시스템

## 1.2 프로젝트 배경

* 카메라를 통해 여러 사람의 손동작을 실시간으로 인식하고, CNN 기반 이미지 분류 모델을 이용하여 가위, 바위, 보를 판별한다.
* 판별된 결과를 바탕으로 2명 이상의 참가자가 가위바위보를 진행할 수 있는 시스템을 구현한다.

## 1.3 프로젝트 목적

* CNN 기반 이미지 분류 모델을 활용하여 사람의 손동작을 가위, 바위, 보로 분류한다.
* 카메라를 이용하여 2명 이상의 참가자의 손동작을 동시에 인식한다.
* 인식된 손동작을 비교하여 가위바위보의 결과를 판단하고 화면에 표시한다.
* 학습된 CNN 모델을 Raspberry Pi에서 실행하여 On-device AI 시스템을 구현한다.

## 1.4 프로젝트 요약

> 카메라로 2명 이상의 참가자의 손동작을 입력받아 CNN 모델이 가위, 바위, 보를 각각 인식하고, 참가자별 선택 결과와 최종 승패 결과를 Raspberry Pi 화면에 실시간으로 표시하는 시스템을 구현한다.

# 3. 프로젝트 기능

| ---------- | ---------------------------------------------- |
| 카메라 입력     | 카메라를 통해 2명 이상의 참가자의 손동작을 실시간으로 입력받는다.          |
| 사람/손 영역 인식 | 화면에서 각 참가자의 손 영역을 찾아 CNN 모델의 입력으로 사용한다.        |

| 참가자별 결과 표시 | 각 참가자의 가위바위보 선택 결과를 화면에 표시한다.                  |
| 승패 판단      | 참가자들의 선택 결과를 비교하여 승자, 패자 또는 무승부를 판단한다.         |

1. 2명 이상의 참가자가 카메라 앞에 위치한다.
2. 각 참가자가 손을 이용하여 가위, 바위 또는 보를 선택한다.
3. 카메라가 참가자들의 손동작을 촬영하고 CNN 모델이 각 손동작을 분류한다.
4. 시스템이 참가자별 선택 결과를 화면에 표시하고, 선택 결과를 비교하여 승패 또는 무승부를 표시한다.

# 4. 시스템 구성

## 4.1 전체 시스템

```text
[펭카 PCWEB400 웹캠]
          ↓
     [영상 입력]
          ↓
    [OpenCV 처리]
          ↓
 [손 영역 검출 및 전처리]
          ↓
     [CNN Model]
          ↓
 [참가자별 가위/바위/보 판별]
          ↓
    [승패 결과 판단]
          ↓
      [결과 출력]
          ↑
 [Raspberry Pi 5 Model B]
```

## 4.2 시스템 구성 요소

| 구성 요소             | 역할                                                                    |
| ----------------- | --------------------------------------------------------------------- |
| Camera            | 펭카 PCWEB400 웹캠을 사용하여 2명 이상의 참가자의 손동작을 실시간으로 촬영한다.                     |
| Raspberry Pi      | 카메라 입력을 처리하고 CNN 모델을 실행하여 참가자의 손동작을 실시간으로 판별한다. 전체 시스템의 실행 환경으로 사용한다. |
| CNN Model         | 입력된 손 이미지를 분석하여 가위, 바위, 보 중 하나의 클래스로 분류한다.                            |
| TFLite/LiteRT     | 학습된 CNN 모델을 Raspberry Pi에서 효율적으로 실행할 수 있도록 경량화된 모델 형식 및 추론 환경으로 사용한다. |
| OpenCV            | 웹캠에서 영상을 입력받고, 영상 처리 및 이미지 전처리, 결과 화면 출력을 담당한다.                       |
| Hand Detection    | 카메라 영상에서 참가자의 손 영역을 검출하여 CNN 모델의 입력으로 사용할 영역을 추출한다.                   |
| Result Processing | 각 참가자의 CNN 예측 결과를 비교하여 승자, 패자 또는 무승부를 판단한다.                           |
| Display           | 참가자별 가위바위보 선택 결과와 최종 승패 결과를 화면에 표시한다.                                 |

## 4.3 하드웨어 구성

| 하드웨어    | 모델                     | 용도                    |
| ------- | ---------------------- | --------------------- |
| SBC     | Raspberry Pi 5 Model B | AI 모델 실행 및 전체 시스템 제어  |
| Camera  | 펭카 PCWEB400            | 참가자의 손동작 촬영           |
| Display | Raspberry Pi 연결 화면     | 참가자별 선택 결과 및 승패 결과 표시 |

## 4.4 소프트웨어 구성

| 소프트웨어          | 용도                        |
| -------------- | ------------------------- |
| Python         | 전체 프로그램 구현                |
| OpenCV         | 카메라 영상 입력, 이미지 처리 및 화면 출력 |
| CNN            | 가위, 바위, 보 손동작 분류          |
| TFLite/LiteRT  | Raspberry Pi에서 CNN 모델 추론  |
| Hand Detection | 참가자의 손 영역 검출              |
| NumPy          | 이미지 데이터 및 배열 처리           |

## 4.5 동작 흐름

1. 펭카 PCWEB400 웹캠을 통해 참가자들의 영상을 입력받는다.
2. OpenCV를 이용하여 카메라 영상을 프레임 단위로 처리한다.
3. 영상에서 각 참가자의 손 영역을 검출한다.
4. 검출된 손 이미지를 CNN 모델의 입력 크기에 맞게 Resize 및 정규화한다.
5. TFLite/LiteRT 기반 CNN 모델을 이용하여 손동작을 추론한다.
6. 각 참가자의 손동작을 `가위`, `바위`, `보` 중 하나로 판별한다.
7. 참가자별 판별 결과를 화면에 표시한다.
8. 참가자들의 결과를 비교하여 승자, 패자 또는 무승부를 판단한다.
9. 최종 가위바위보 결과를 Raspberry Pi 화면에 출력한다.
