* pruning : 필요없는 w => 0 / w 의 개수,구조 를 줄이는데 도움
* clustering : 비슷한 w => 같은값 / w 종류를 줄임
* quantization : fp32 -> int8 처럼 숫자를 작게 표현 / w,activation 등.. 표현 비트 수 ↓
* QAT : 양자화를 고려하며 학습

tfmot의 협업 경량화 기술
- PQAT : w 를 pruning 하면서 도시에 양자화를 고려하면서 학습 / pruning -> QAT
- CQAT : clutsering -> QAT
- sparsity preserving clustering: pruning -> clustering
- PCQAT : pruning -> clustering -> QAT
