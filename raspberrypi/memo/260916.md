# quantizations : 딥러닝 모델의 숫자를 더 적은 비트로 표현 -> 모델 크기,연산량 줄이기
                 Quantization
                       │
       ┌───────────────┼────────────────┐
       │               │                │
    방법/시점        간격 방식        양자화 단위
       │               │                │
   ┌───┴───┐       ┌───┴────┐      ┌────┴─────┐
   │       │       │        │      │          │
  PTQ     QAT   Uniform    Non   Layerwise ...
   │                    -Uniform
   ├─ Static
   │
   └─ Dynamic

PTQ / QAT
→ "언제 양자화할까?"

Static / Dynamic
→ "양자화 범위를 언제 결정할까?"

Uniform / Non-uniform
→ "양자화 값의 간격을 어떻게 할까?"

Symmetric
→ "0을 기준으로 대칭적으로 할까?"

Granularity
→ "얼마나 작은 단위로 양자화할까?"

- uniform quantization 
    : 숫자 사이의 간격을 똑같이 나누는 방식
    * 일정한 간격 / 계산 간단 / 하드웨어 구현 쉬움 / 딥러닝에서 많이 사용
    * w / activation 을 줄일때 많이 사용
                vs
- Non-uniform quantization
    : 숫자 사이의 간격이 일정하지 않은 방식
    * 데이터가 특정 구간에 몰려있을 때 유리

- symmertric Quantization
    : 대칭 양자화 / 0을 기준으로 양쪽 범위를 대칭

(ex) symmetric + uniform
w : [-0.82, -0.31, -0.05, 0.12, 0.44, 0.79]
양자화할 범위: -0.82 ── -0.41 ── 0 ── +0.41 ── +0.82 / 일정한 간격으로 대칭되게 나누기
float32                    int8

-0.82       →              -127
-0.41       →               -64
 0          →                 0
+0.41       →               +64
+0.82       →              +127

- post tranining quantization(PTQ)
    : 학습이 끝난후 양자화
    * 적용 쉬움, 최적화 간단 / 정화도 조금 떨어질 수 있음
    * 이미 학습이 끝난 모델을 빠르게 경량화 하고 싶을때 사용
    * tensorFlow -> TFLite

- static quantization
    : 양자화에 사용할 범위(scale,zero point ..)미리 결정
        학습된 모델
            ↓
        Calibration Data 입력
            ↓
        Activation 값들의 범위 확인
            ↓
        Scale / Zero Point 결정
            ↓
        INT8 모델

    activation 범위 결정을 위해 calibaration data 사용
    * 추론할 때마다 activation 범위를 계산할 필요가 없다 -> 빠르게 계산 가능
            vs
- dynamic quantization
    : 추론할 때 필요한 값을 동적으로 계산
           입력
            ↓
        Activation 범위 계산
            ↓
        Quantization
            ↓
           연산
    * calibration 과정 간단, 데이터 분포가 계속 달라지는 경우 유연 / static보다 추가 연산

- quantization granularity
    : 얼마나 작은 단위로 양자화 할것?
        FP32 모델
        ↓
        양자화 영향을 고려하면서 학습
        ↓
        양자화 모델
    - layerwise : 가장 큰 단위 / layer 하나 통째로 하나의 양자화 단위로 사용
        Layer 1
        ┌──────────────┐
        │              │
        │   Weights    │ → scale 1개
        │              │
        └──────────────┘

        Layer 2
        ┌──────────────┐
        │              │
        │   Weights    │ → scale 1개
        │              │
        └──────────────┘
    - groupwise : channel보다 조금더 큰 단위 or 여러 값을 묶어서 양자화
        Weights

        Channel 1 ─┐
        Channel 2 ─┤ → Group 1 → scale 1
        Channel 3 ─┘

        Channel 4 ─┐
        Channel 5 ─┤ → Group 2 → scale 2
        Channel 6 ─┘

    - channelwise : channel 마다 따로 양자화
        Conv2D
        ↓
        Channel 1 → scale 1
        Channel 2 → scale 2
        Channel 3 → scale 3
        Channel 4 → scale 4
        => 각 채널의 특성에 맞는 스케일 사용 가능

    - sub-channelwise : 더 작은 단위로 나누어 양자화
        Channel
        ┌──────────────────────┐
        │  A  │  B  │  C  │ D │
        └──────────────────────┘
        ↓     ↓     ↓    ↓
        scale1 scale2 scale3 scale4

- quantization aware training (QAT)
    : 학습 할 때무터 INT*로 바뀔것을 고려하며 학습
        학습
        ↓
        FP32 모델
        ↓
        양자화
    * 일반적으로 PTQ보다 양자화 후 정확도 손실을 줄이는데 유리
    * 다시 학습해야함 / 학습 시간 필요 / 구현 복잡

|           | PTQ          | QAT          |
| ------    | ---------    | ------------ |
| 양자화 시점 | 학습 후       | 학습 중         |
| 추가 학습   | ❌          | ✅            |
| 구현       | 비교적 간단    | 복잡           |
| 시간       | 적게 걸림      | 많이 걸림        |
| 정확도 손실 | 발생할 수 있음  | 줄이는 데 유리     |
| 사용 상황  | 빠른 모델 경량화 | 정확도 손실이 큰 경우 |
